Copperwake is an original, offline-playable crime adventure in a compact copper-smelting port city at dusk. Steal a delivery car, work four short missions, and outrun the harbour police across its streets and wharves.

## Run it

```sh
python3 -m http.server 8080 --directory game
```

Then open http://localhost:8080 in a desktop browser.
